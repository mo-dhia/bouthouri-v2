# Experiment media provenance

Retained at the user’s request for the adapted Carter Ogunsola Lab studies. These are reference experiments, not claims of original Bouthouri client work. Original study links remain in each page’s Notes.

- Original studies and published example code: https://carterogunsola.com/lab (inspected 2026-10-29).
- Print photographs: Franco Dupuy and Fanette Guilloud, as credited by the reference.
- Lantern: Khronos glTF Sample Assets, immutable revision 2bac6f8c57bf471df0d2a1e8a8ec023c7801dddf. The adjacent original README retains Microsoft/sbtron/Frank Galligan attribution and CC0 notice.
- Scrollbar retains the reference’s music tracks, cover images, icon/motion credits and public example behavior. Those credits do not imply that all other reference media shares the Lantern’s CC0 license.
- Orb worker: adapted from the public Vocal Orb example. Its optional on-device model path retains the original Moonshine/Silero/TinyBERT/Kokoro pipeline. Kokoro text handling derives from kokoro-js (Apache-2.0), as noted in the worker. No speech model is included in the initial page load.
