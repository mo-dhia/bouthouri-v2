**Location:** `src/components/layout/route-surface/route-surface.animate.ts:107` returns on a URL mismatch; lines150–154 retain the navigation watchdog, whose line152 hard-assigns the original target. **Concrete trigger:** Start a managed Vision→Services click, let cover finish, and leave the destination owner pending. Activate an unclaimed Projects Next Link before Services commits. A hash/native route that supersedes the transaction requires the same cancellation discipline; this proof specifically models an unclaimed Next Link.

This is a controller/lifecycle reproduction with inert DOM and clock adapters, not a browser claim that a particular network delay occurred.
