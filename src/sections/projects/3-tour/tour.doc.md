# 360° Tour

The separate nineteenth Projects card opens `/[locale]/projects/360-tour`.
Both locales are statically generated by the existing project detail route,
with canonical/alternate metadata and sitemap entries. The established editorial
shell, field, route cover and header remain the page owners, as on Heart.
This is an Artefact project, independent of the nine Carter interaction studies.

`tour.tsx` owns the title, café poster, description, notes, entry/retry/close
labels, original-site link and return navigation. The server response contains
no iframe. No-JS or failed-controller visits keep the poster and useful links.
`tour-gate.tsx` renders null and imports only the controls controller.

`tour.logic.ts` publishes route readiness immediately from server content. The
heavy viewer is never a prerequisite for route entry or navigation. Only the
visitor's Enter action creates the same-origin Pano2VR iframe. Loading has a
45-second ceiling, a retry state and an immediately available Close action.
Context loss returns to the poster. Each attempt owns its event registrations,
polling and timeout. Closing, retrying or unmounting removes the browsing context
and its GPU/tile resources, cancelling all host listeners and timers.

The copied three-viewpoint café tour preserves Artefact's room hotspots, zoom,
VR/fullscreen skin and watermark. Adjacent-view preloading stays disabled.
Visibility, the menu and viewport intersection park interaction and rotation;
reduced motion and quiet mode stop automatic rotation while preserving manual
exploration. Fullscreen is observed in both documents. The original viewer owns
its render loop; the host adds no animation loop. Generated skin controls gain
localized accessible labels and Enter/Space activation.

The stage fills the live physical height with the existing header clearance.
Desktop/tablet/mobile use the 1920/768/412 reference widths in exclusive CSS
profiles. The host converts source control, watermark and hotspot artwork sizes
to the selected width scale; native panoramic projection stays in physical
coordinates. Resizing does not restart the viewer. The iframe's generated
distribution is isolated from application CSS and initial bundles.

## Validation

- `bun run check`, `bun run build`, `bun run test:ssr -- <production-server>`.
- Controller coverage: no eager viewer, close during loading, stale failed
  attempts, timeout/retry, visibility/menu/reduced motion and WebGL context loss.
- Route coverage: poster releases the managed route independently of the viewer.
- Browser: desktop 1920×1080, Arabic tablet 768×1024, mobile 412×915 and
  Arabic short mobile 412×700; drag, hotspot navigation, close/reopen, localized
  labels, no horizontal overflow, no-JS content and failed-config recovery.
- Fullscreen enters a 1920×1080 viewer and exits correctly; keyboard zoom works,
  Arabic skin controls are localized, and resizing to 650px scales the controls
  by `650 / 768` without replacing the player. A blocked controller leaves the
  poster and all three links available. A lost context removes the live iframe.
- Media provenance and checksums: `public/assets/projects/tour/README.md`.
