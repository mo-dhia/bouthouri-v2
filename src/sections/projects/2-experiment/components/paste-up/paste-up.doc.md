# paste-up

Six identity-bearing prints with Index/Spread/Strip boards. Source spring/transition math, image claims and optional WebGL bending remain local. Decode callbacks reject disposed mounts; shaders/images never join initial server/client content imports. Tabs are centered to avoid the own Notes row.

Source: https://carterogunsola.com/lab/paste-up (public example/runtime inspected 2026-10-29).

The parent experiment contract owns loading, first presentation, profile remounts,
visibility, common resources and failure fallback. Styling stays scoped to the
child reference camera; all DOM lengths scale by the inherited design unit.
Media attribution is retained in `public/assets/projects/experiments/README.md`.
