# vocal-orb

Source black-hole ray march, bloom/compositing, glyph and pointer springs. GLSL lives in orb-shaders.js; optional speech worker is a separate public module created only on intent. orb-input.ts rejects late/superseded permission, stopping every late track. Menu/hidden/departure stops listening. No real audio was captured during implementation QA.

Source: https://carterogunsola.com/lab/vocal-orb (public example/runtime inspected 2026-10-29).

The parent experiment contract owns loading, first presentation, profile remounts,
visibility, common resources and failure fallback. Styling stays scoped to the
child reference camera; all DOM lengths scale by the inherited design unit.
Media attribution is retained in `public/assets/projects/experiments/README.md`.
