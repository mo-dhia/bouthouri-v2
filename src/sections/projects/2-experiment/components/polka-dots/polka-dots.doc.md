# polka-dots

Canvas spring/ripple field. Retains source grid, pointer force, click wave, center-stagger intro and settling thresholds. Source finite elastic curve uses the environment motion owner. Dispose kills its intro/tick, observers and pointer registrations.

Source: https://carterogunsola.com/lab/polka-dots (public example/runtime inspected 2026-10-29).

The parent experiment contract owns loading, first presentation, profile remounts,
visibility, common resources and failure fallback. Styling stays scoped to the
child reference camera; all DOM lengths scale by the inherited design unit.
Media attribution is retained in `public/assets/projects/experiments/README.md`.
