# dial

DOM/SVG wheel and knob. Retains source detents, wheel/drag/key input, damped momentum, snap and sound tick. Tick audio respects the global sound preference. Icons and ordinary platform destinations remain the reference demo; they are not Bouthouri social account claims.

Source: https://carterogunsola.com/lab/dial (public example/runtime inspected 2026-10-29).

The parent experiment contract owns loading, first presentation, profile remounts,
visibility, common resources and failure fallback. Styling stays scoped to the
child reference camera; all DOM lengths scale by the inherited design unit.
Media attribution is retained in `public/assets/projects/experiments/README.md`.
