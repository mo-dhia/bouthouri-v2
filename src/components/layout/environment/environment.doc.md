## Local placement adaptation

The locale server layout renders only a decorative parking slot and null client
gate. Server route content stays in its original composition. The small owner
module imports Three/material code only after an eligible route lease. HOME's
first resource boot keeps its existing idle callback with 1200ms timeout (32ms
fallback); an editorial lease starts through its existing deferred shell load.

The resource is document/locale-owned, while its **same imperative host** is
prepended to the current HOME `.experience` or editorial root. Release parks that
same host in the connected locale slot before route DOM removal. This deliberately
adapts the source's sibling placement to the accepted opaque/isolated local
shells. No journey transparency, stacking retune or design geometry changed.
The field retains its existing fixed top-anchored rectangle and three profiles.
The slot is fixed and decorative, contributes no document flow and owns no copy.

`createPersistentStoryEnvironment(parking, { reduced })` owns renderer, canvas,
field/material history, global pointer/menu/context listeners and the existing
demand scheduler. Its `bind(binding)` returns `{ invalidate, release }` for one
generation of route attachments. Each bind replaces only stage/frame/interaction/
hero listeners and the page visibility observer. Old releases and queued observer
callbacks cannot detach a newer binding. The standalone `createStoryEnvironment`
and cleanup-only `mountStoryEnvironment` adapters remain available.

The small coordinator owns idle/import cancellation, latest binding/mode adoption
and final disposal. A completion without a live route lease creates no resource;
a later lease can use the loaded module. Import failure is optional and does not
retry on every supported route. Excluded routes invalidate pending generations
and dispose resources; later eligible entry can start fresh. HOME, Vision,
Services and Contact are supported in the current locale; Projects/nonnarrative
routes intentionally decline this enhancement. Source scope was the whole
portfolio layout, so this exclusion is a local scope policy. Full document/locale
replacement legitimately starts a new clock/context.

## State and render contract

Editorial entry selects `time=448`, `environment=.28`, quiet `.65` (Vision/
Services), `.9` (Contact) or `1` (focused Contact). It **retains narrative work
travel** from the preceding route. A direct editorial document uses initial
travel `-1.35`. HOME binding reads its current frame/work travel and full-precision
displayed hero pose; HOME's existing reset/restore remains the narrative owner.
Material prior travel, time, stroke, pulse and settle budget survive both routes.
During supported zero-binding gaps, quiet becomes zero, hero presence is neutral,
and travel/phase/history remain. Binding alone does not reset shared pointer input.

The existing per-stage journey render-owner protocol is unchanged. A pending
HOME tick parks idle/settling work immediately, including on late binding. Its
current frame event submits after work/systems publication in that transaction;
ordinary publications coalesce through the existing demand RAF/timer. There is
no new RAF, progress store or clock. Reduced mode resets transient targets only
on an actual change. MENU quiet tail/drift, visibility pause, fixed-profile field
allocation and lazy context restoration retain the existing controller policy.

HOME's background lease lives in `StorySceneGate`, outside the failed optional
object child. Quiet/system reduced/object failure update its effective mode;
object failure does not dispose the global field. Route release removes old
object guards/grab state without resetting field or pointer coordinates. Portrait
and footer publishers carry mount sequence/owner identity. The collector rejects
older source events and releases only projections belonging to the departed page;
an old cleanup cannot erase a newer same-source publisher or the other source.
